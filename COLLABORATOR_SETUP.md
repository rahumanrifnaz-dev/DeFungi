# Collaborator Setup

After the shared GitHub repository is created and the first project baseline is pushed, the repository owner should add the other real group members as collaborators.

## Add Collaborators

1. Open the GitHub repository in a browser.
2. Go to `Settings`.
3. Open `Collaborators` or `Collaborators and teams`.
4. Select `Add people`.
5. Add each real member using their actual GitHub username or email address.
6. Ask each member to accept the invitation from their own GitHub account.

Do not guess usernames. Do not add fake accounts. Each member must use their own GitHub account and their own local Git identity.
