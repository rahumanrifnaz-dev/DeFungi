\section{Pretrained Lightweight Models}
\textbf{Owner: Lavanathan.J -- 230371R}

Two ImageNet-initialized lightweight architectures were evaluated using the same canonical DeFungi split membership as the custom CNNs. The Session 3 transfer-learning runs used 64$\times$64 inputs to remain consistent with the assignment image-size constraint. Each model replaced the ImageNet classifier with a five-class DeFungi head.

\subsection{MobileNetV2}

MobileNetV2 was trained in two stages: three frozen-head epochs at learning rate 0.001, followed by eight fine-tuning epochs of the upper 20 non-BatchNorm backbone layers at learning rate 0.0001. Validation loss selected the saved checkpoint.
