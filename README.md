# EN3150 Assignment 03

## Resource-Constrained CNN for Edge Image Classification

This repository contains the implementation and development work for **EN3150 Assignment 03**.

The objective of the assignment is to develop and compare convolutional neural network architectures for resource-constrained edge image classification.
